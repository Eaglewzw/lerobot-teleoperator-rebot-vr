# 高速直线侧摆控制配置

`config/dual_mit_split_q1.yaml` 在双臂 MIT split 模式下启用肩部侧向误差加权、q1 有界位置参考、q2 Kd=5 和已发送速度同步。它保留原位置/姿态映射、关节速度与加速度上限、退出归零容差。原 `dual_mit_split.yaml` 可用于参数回退（位置求解器优化仍生效）。

检查配置（不打开 VR 或 CAN）：

```bash
rebot-vr-teleoperate-dual --config config/dual_mit_split_q1.yaml --dry-run
```

实际运行，沿用项目正常启动和急停要求：

```bash
rebot-vr-teleoperate-dual --config config/dual_mit_split_q1.yaml
```

新参数：

| 参数 | 配置值 | 行为 |
| --- | --- | --- |
| `split_contour_mode` | `shoulder_lateral` | 根据肩轴与请求运动方向，额外惩罚侧向速度误差；不额外加强竖直任务，不锁定 q1 |
| `split_contour_weight` | `25.0` | 上述侧向代价权重 |
| `qp_use_sent_velocity` | `true` | 下一次 QP 使用实际已发送的速度作为历史，避免超时后电机仍在减速而规划从零开始 |
| `mit_q1_reference_error_deg` | `2.0` | 积分已限幅的 q1 速度构造位置参考，参考相对反馈始终受此窗口及现有硬件位置限制约束；0 关闭 |
| `mit_kd` | `[4, 5, 4, 0.5, 0.5, 0.5]` | 只把原 q2 阻尼/速度增益从 4 提到 5 |

q1 参考在停止、HOLD、速度过期时清除，启动/归零的显式位置指令保持原语义。该参数仅允许 MIT split 模式，范围 0–2°。它不是增加力矩上限，也不是取消加速度保护。

本配置针对已验证的高速直线回程问题。q1 仍需要跟随正常侧向手柄输入；非零初始 q1 角度下，保持机器人基座坐标中的直线也可能需要少量 q1 转动。应同时检查轨迹偏差和响应，不能将任何 q1 转动都判为侧摆。

原有前后方向跟随误差仍然存在，这个配置不表示所有姿态、载荷和更高速度都已验证。它不包含诊断脚本中的额外 q1 零位对齐动作。

位置模式的三轴 QP 使用有界直接求解，保留相同目标函数、运动约束和 8 ms 超时保护；姿态模式求解方式不变。

验证范围：最终配置完成两组独立双臂同步高速直线测试，每组三次往返，输入峰速约 0.618 m/s、正向行程约 246 mm，无保护中止，q1 摆幅均小于 0.16°、横向最大误差小于 1.2 mm。前后最大跟随误差仍约 60–79 mm；这不是全方向高精度跟随或任意轨迹的验收。此前单臂测试使用侧向权重 9、同步关闭，不能将其数字当作最终配置的单臂实测结果。
