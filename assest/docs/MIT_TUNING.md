# MIT 分轴调参

`rebot-mit-tune` 是独立于 VR、QP IK 和笛卡尔状态机的实机诊断入口。它只复用正式遥操使用的 MIT 发送器、Pinocchio 重力补偿和统一失能流程，因此测试得到的增益可直接用于 `config/mit.yaml`。

## 数据流

```text
平滑单轴轨迹 -> 六轴 MIT 位置/速度目标 -> MotorBridge -> 电机
                         ^                     |
                         |---- 六轴反馈 -------|
```

未选中的五个关节保持测试开始时的位置。夹爪保持连接时的位置。默认轨迹为：

```text
中心 -> +5 deg -> 中心 -> -5 deg -> 中心
```

每段使用五次多项式平滑过渡，并重复两轮。q1 单轴偏移硬限制为 `90 deg`，
q2-q3 为 `30 deg`，q4 为 `60 deg`，q5-q6 为 `88 deg`；
所有目标还必须满足带 `2 deg`
裕量的关节限位。

`max-relative-target-deg` 限制单帧命令相对实际反馈的距离，
`max-tracking-error-deg` 是跟踪误差停机阈值；二者独立于总测试行程。

无法人工精确摆到测试中心时，可用
`--prepare-pose-deg 0 -45 -45 0 0 0`。工具会从当前反馈生成最小冲击轨迹，
默认峰值速度不超过 `0.3 rad/s`；准备姿态到位并通过误差检查后才开始单轴实验。

## 当前实机整定结果

在 `[0, -45, -45, 0, 0, 0] deg` 准备姿态附近完成单轴往返与高速停止测试后，
当前候选增益为：

- `Kp = [25, 30, 30, 10, 10, 10]`
- `Kd = [5, 5, 4, 0.5, 0.5, 0.5]`

q3 高速停止仍会通过惯性耦合短暂带动 q2。q2 已使用 `Kd=5`，继续将其
`Kp` 从 30 提高到 35 没有明显收益；剩余误差需要通过降低加速度或加入惯性和
科氏力前馈处理，不能继续依靠提高关节增益消除。

## 运行

重新安装包以生成命令入口：

```bash
cd /home/verser/Python/lerobot-teleoperator-rebot-vr
uv pip install --python /home/verser/Python/lerobot/.venv/bin/python --no-deps -e .
```

q1 基线测试：

```bash
rebot-mit-tune \
  --robot-port /dev/ttyACM0 \
  --joint q1 \
  --step-deg 5 \
  --kp 20 \
  --kd 5 \
  --csv-log logs/mit_tuning/q1-kp20-kd5.csv
```

程序先显示测试范围和增益，此时尚未连接电机。清空工作空间、托住机械臂并准备 `Ctrl+C`，确认后输入大写 `RUN`；随后程序连接电机、锁存当前姿态并开始测试。

## 安全行为

- 偏移端点必须位于软件限位内侧至少 `2 deg`。
- 连续反馈异常、非使能状态、超温、超速、跟踪误差或其他关节偏移过大时中止。
- 正常完成时选中关节回到测试起点。
- `Ctrl+C` 或异常时先发送当前反馈位置的零速度 HOLD，再执行七轴失能和关闭连接。
- MotorBridge 当前不提供可用的反馈接收时间戳；工具能识别读取失败，但不能证明缓存反馈的新鲜度。
- 工具不能识别碰撞、异响和线缆拉扯，现场人员必须负责急停判断。

## 输出

每次运行生成三个文件：

- `*.csv`：六轴目标、实际位置、速度、扭矩、重力前馈、温度、状态和通信耗时。
- `*_summary.json`：选中关节的 RMSE、稳态偏差、超调、稳定时间和后半段振幅。
- `*_shutdown.json`：逐电机失能尝试和可观测状态。

比较两组 `Kp/Kd` 时，保持机械臂起始姿态、`step-deg`、过渡时间、重力倍率和负载一致，只改变一个参数。
