## 1. 测试方法

### 1.1 VR 数据注入闭环仿真（结构跳变统计）

将模拟的 PICO 手柄样本（`ControllerSample`：位置、四元数、grip、trigger、纳秒级时间戳）**逐帧注入完整控制管线**：

```
ControllerSample
  → RelativePoseMapper（Grip 离合 + 相对映射 + 8Hz 低通滤波）
  → ClosedFormWristSolver（q4-q6 闭式解）
  → LatestOnlyIKWorker（q1-q3 异步位置 IK，1000Hz）
  → shape_joint_position_command（限速/限加速度整形）
  → 模拟机器人反馈闭环（实际关节以 ≤3 rad/s 跟随命令）
```

每种配置运行 **13 条轨迹 × 323 帧 = 4199 帧**，两种配置共 **8398 帧（≥1000 例）**：

| 配置 | position-scale | orientation-scale |
|---|---|---|
| A | 1.0 | 0.0（您实机观察到跳变的工况） |
| B | 1.0 | 1.0 |

轨迹覆盖：三轴正弦扫掠、水平圆（r=0.35/0.55 m）、平滑随机路径、纯腕部旋转扫掠、圆+滚转复合、**越过 q1=±90° 的侧向大摆（past_90_left/right）**、**q1 0→180° 水平大弧（wide_arc_180 / wide_arc_with_yaw）**。

**结构跳变定义**：稳态 ACTIVE（相邻帧同轨迹、同 generation、均 active）内，q1-q6 目标角单帧变化 > 15°。阈值敏感性：10° → 94/97 次；15° → 53/56 次；20° → 42/45 次（配置 A/B）。

### 1.2 q4-q6 两组解算对比

| 组 | 方法 |
|---|---|
| 旋转矩阵直接映射（naive） | 对目标末端旋转矩阵直接做 ZYX 欧拉分解赋给 q4-q6，**不补偿 q1-q3、不含腕部框架常量**（与工程公式逐项一致的分解器，只是去掉了 `wrist_base_rotation(q123)^T` 与 `wrist_frame_constant^T` 两项修正），并裁剪到与闭式组相同的关节限位 |
| 闭式腕部求解（本工程） | `ClosedFormWristSolver.solve()`，含奇异点 fallback 与限位裁剪 |

场景 1：q1 从 -150°→150°（q2=q3=-0.8 rad），目标姿态固定（orientation-scale=0 工况）。
场景 2：q1-q3 固定为弯曲姿态 [0.5, -1.0, -0.6] rad，手柄绕基座 Z 轴 ±180° 旋转。

## 2. 结构跳变统计结果（核心结论：**存在结构跳变**）

| 指标 | 配置 A (ori 0) | 配置 B (ori 1) |
|---|---:|---:|
| 注入帧数 | 4199 | 4199 |
| 稳态 ACTIVE 帧对 | 3887 | 3887 |
| 结构跳变次数（>15°/帧） | **53** | **56** |
| **跳变概率** | **1.36%** | **1.44%** |
| IK 未收敛帧（ik_hold） | 1695 | 1695 |
| 腕部限位裁剪帧（wrist_clip>0） | 2025 | 2224 |

分轨迹跳变数（配置 A）：

| 轨迹 | z_sweep | circle_r035 | big_circle | random×2 | combined | past_90×2 | wide_arc×2 | 其余 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 跳变 | 4 | 3 | 7 | 6 | 3 | 4 | **26** | 0 |

**最大跳变 170°–180°/帧，全部落在 q4-q6 组**（wrist_flex / wrist_roll），且伴随 90°–100° 的腕部裁剪量。q1-q3 无单独跳变（IK 的 branch_jump 保护生效）。跳变集中在 **q1 穿越 ±90° 的轨迹**（wide_arc、circle、past_90），与开环分析的预测一致，**复现了您实机观察到的现象**。

跳变机制（仿真证实）：

```
q1 从 89° → 91° 时:
  非奇异分支解 ≈ (q4=0, q5=±90, q6=0) 之外需要 (q4≈∓180°, q6≈±180°) 才能保持姿态
  → 裁剪到 (q4=∓80°, q6=±90°)
  → 目标角单帧从 (0, ±90, 0) 跳到 (∓80, ±90, ±90) → 170° 结构跳变
```

即：跳变不是求解器数值发散，而是**"保持固定姿态所需的 q4/q6 超出限位 → 裁剪分支进/出切换"造成的阶跃**。

## 3. 两组 q4-q6 解算对比结果

| 指标（场景 1：q1 扫掠、姿态固定） | 旋转矩阵直接映射 | 闭式腕部求解 |
|---|---|---|
| q4 范围 | 恒定 ≈ 0° | -80° … +89.95° |
| q5 范围 | 恒定 ≈ 0° | -89.95° … +89.95° |
| q6 范围 | 恒定 ≈ 0° | 0° … 90° |
| 末端姿态误差 | 随 q1 线性增大，最大 **150°** | 限位内 ≈ 0.0002°；裁剪区最大 87° |
| 超限裁剪 | 40.5% 的 q1 区间不可用 | 40.5%（|q1|>90°）裁剪，最大违约 100° |

场景 2（手柄旋转 ±180°）：闭式解在限位可行区间内精确跟踪（误差 <0.01°），超出限位后饱和；直接映射因忽略 q1-q3 耦合，误差 119°–180°，**物理上不可用**。

结论：**闭式腕部求解显著优于旋转矩阵直接映射**（姿态误差差 2–3 个数量级）；但两者在 |q1|>90° 区域都受限于腕部关节限位，闭式解在该区域会出现第 2 节所述的结构跳变。

## 5. 验证

- 方法学对抗审查（独立 agent）：发现并确认了仿真时间戳缺陷（已修复后重跑全部数据）；对比脚本的"直接映射组未裁剪"不公平问题已修复为双组同限位裁剪。
- 结果独立复算（独立 agent、自写解析代码）：跳变统计全字段**精确一致**（53/56、概率 1.3635%/1.4407%、分轨迹、Top-5）；对比数据 301+361 行重算误差 ≤5e-5°；图与 CSV 逐项一致。两项均 PASS。

## 6. 局限

- 仿真机器人完美跟随且未启用反馈误差绑定，HOLD/反馈故障路径未触发；实测中若叠加 CAN 抖动、HOLD 恢复，跳变可能更多。
- 15° 阈值会把 15–28.6° 的求解器合法重构计为跳变（本数据中最大合法单帧步进约 9–15°，影响很小，且 Top 跳变均为 170–180° 的真实阶跃）。
- 圆周轨迹部分超出 q1 限位（±150°），以 ik_hold 形式出现，不计入跳变。

## 7. 建议

1. 采集时尽量避免 q1 进入 ±90° 以外区域（或限制横向手柄行程）；
2. 若需全工作空间无跳变：对 q4/q6 裁剪引入**滞后/速率限制**（进出裁剪分支时渐变过渡），或扩大腕部硬件限位；
3. 保持当前的闭式腕部求解，不要改为旋转矩阵直接映射。
